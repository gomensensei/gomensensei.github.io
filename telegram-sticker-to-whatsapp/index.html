QUICK START

四步完成轉換

  1. 1

    下載及解壓

    下載 Windows ZIP，將整個資料夾解壓到電腦。

  2. 2

    雙擊啟動

    開啟「啟動轉換工具.bat」。首次使用會自動安裝轉換元件。

  3. 3

    貼上連結

    輸入 Telegram sticker pack 連結及 Bot Token，按一鍵轉換。

  4. 4

    加入 WhatsApp

    下載 .wastickers，傳送到手機後以 Sticker Maker 開啟。

不同 Wi-Fi？

改用「直接下載」即可

QR Code 是電腦本機分享，所以手機與電腦需要在同一個 Wi-Fi。若不在同一網絡，請在轉換完成頁按「直接下載」，再經 AirDrop、Quick Share、雲端硬碟、Telegram Saved Messages 或 USB 將 .wastickers 傳到手機。
